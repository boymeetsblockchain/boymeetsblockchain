### 🩺 Featured project

**[RehabWise](https://rehabwise.online)** — a stroke telerehabilitation platform built end-to-end (NestJS, PostgreSQL, Prisma, Next.js), with Cloudflare R2 for video, Africa's Talking for SMS alerts, and Daily.co for live patient-therapist video consultations. Designed with a clinical data model informed by my physiotherapy background.
